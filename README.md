## Running any Node.js task
```bash
cd task1-html-server      # or any other task folder
npm install
npm start
```
Then open http://localhost:3000. Tasks 3 and 4 need no installation: open their
`index.html` file directly in a browser.

## Tech used
HTML5, CSS3, Bootstrap 5, vanilla JavaScript, Node.js, Express, EJS, MongoDB
(Mongoose), JWT, bcrypt, Open-Meteo and GitHub APIs, OAuth 2.0, Redis (optional).

## Note on `node_modules`
The `node_modules` folders are not included, to keep the archive small.
`npm install` recreates them from each `package.json`.
